# 四种开场模式

## A. 同行交流（peer_exchange）— 默认
结构：〔对方的具体内容〕→〔你的相关经历里一个具体细节〕→〔一个具体问题〕
适合：有公开分享 / 文章 / 演讲的人。

## B. 作品敲门（artifact）— 最强
结构：〔我基于你们的平台 / 场景做了 X〕→〔一个有意思的发现〕→〔想请教你的看法〕
适合：平台型团队（百炼 / 方舟 / Dify / 千帆），开源团队（先提 PR 再私信）。
这也是你的 social proof：同一个作品可以发公众号 / LinkedIn，作战卡里会提示。

## C. 同源切入（affinity）
结构：〔共同点：校友 / 同乡 / 海归 / 同社区〕→〔对方团队在做的事〕→〔一个问题〕
适合：脉脉 / LinkedIn 上能看到共同点的人。

## D. 中澳桥梁（au_bridge）
结构：〔你在澳洲企业一线看到的具体现象〕→〔和国内做法的一个差异〕→〔问对方怎么看〕
适合：有出海 / 海外客户 / ANZ 团队的公司；也在为 2027 回澳铺路。

## Follow-up 1（48–72h）
"补一个我这边的小实验结果 / 一份整理"，附一句话结论。不写"在吗"。

## Follow-up 2（+7 天）
"最后一次打扰：如果不方便，是否有更合适的同事我可以请教？"

## 转到岗位
"聊下来觉得你们的方向和我的经历很贴。今年团队有 junior / graduate 的 headcount 吗？如果合适我想正式走一下流程，走内推还是直接发简历给你更方便？"
