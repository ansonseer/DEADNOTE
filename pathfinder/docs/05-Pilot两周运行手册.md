# 05 · Pilot 两周运行手册

目标：**20 家公司 → 50 个相关岗位 → 30 个关键人物 → Top 10 作战卡 → 10 条第一条私信 → ≥ 2 段对话 → 1 个内推路径**。
每天 60–90 分钟。日报（`pf brief`）会告诉你当天做什么；这份手册告诉你为什么这么排。

## 第 0 天：把弹药库填满（1 小时）

- `config/profile.yaml`：每个 TODO 换成真实的项目名、客户类型、数字、你亲手做的部分。**文案质量 = 这个文件的质量。**
- `pf init`：看 20 家 pilot 是不是你想要的；不是就改 `seeds.yaml` 的 `screen_boost` 或 `tier`。
- 决定运行模式：有搜索 key → API 模式；没有 → packet 模式（用 Claude Code 当研究员）。

## 第 1 周：研究（不发任何消息）

| 天 | 做什么 | 命令 | 产出 |
|---|---|---|---|
| 1 | 团队假设 | `pf scan` | 每家 3–6 个团队假设 |
| 2–3 | 岗位发现：每家看官网 + BOSS + 牛客，录入 2–4 条真实 JD | `pf discover` → `pf jobs add` → `pf discover --company X` | 50 条岗位，已分类 |
| 4–5 | 团队研究：Top 12 家（按 screen_score） | `pf research`（或 packet） | 每家 1 个已验证团队 + 信号 |
| 6–7 | 找人：每家 2–3 人 | `pf people packet` → `pf people add` → `pf people assess` | 30 人，已评估 |

周末：`pf rank && pf cards && pf brief`。看 Top 10，问自己三个问题：团队方向对吗？人对吗？hook 具体吗？不对的回去补研究，不要带着模糊的卡进入第 2 周。

## 第 2 周：触达

| 天 | 做什么 |
|---|---|
| 8 | `pf outreach` 生成 A 类机会的文案；自己改到"像你说的话"；发 3–5 条；每条 `pf crm touch --kind first_msg` |
| 9 | 再发 3–5 条。同时开始做 1 个作品敲门的小实验（针对 Top 1 团队） |
| 10 | 日报会列 follow-up 1；每条都要"给东西" |
| 11 | 回复的人 24h 内推进；提议 15 分钟语音 |
| 12 | 发作品（公众号 / LinkedIn），`pf crm asset` 记录；用它去敲 1–2 个平台型团队 |
| 13 | follow-up 2；无回复的 parked，切换同团队另一人 |
| 14 | 复盘：`pf status`、漏斗数字、每条私信的回复情况；改一处配置或 prompt |

## 两周结束时的判断标准

| 指标 | 目标 | 低于目标时看哪里 |
|---|---|---|
| 回复率 | ≥ 20% | 文案（hook 不具体）> 人（角色不对）> 团队（方向不对） |
| 对话数 | ≥ 2 | follow-up 有没有给价值 |
| 内推路径 | ≥ 1 条 L3+ | 是否太早开口 |
| 作品 | ≥ 1 篇 | 时间分配 |

## 每天的固定动作（15 分钟）

```
pf brief          看今天 3–5 个动作
（去做）
pf crm touch ...  每个动作记一笔
pf crm done ...   完成的任务勾掉
```

## 第 3 周起

Pilot 变成常态：每周新增 5 家公司（bench 里往上提）、5 个人、5 条私信、1 篇作品。`pf run-all --company X` 一家一家加。
