# 03 · 找人与人脉路径

## 找谁（按优先级）

1. **Hiring Manager / 团队负责人**：拥有 headcount 的人。回复率不一定最高，但一条回复顶十条。
2. **Team Lead / 解决方案负责人**：知道团队真实需要什么，能把你的名字带到 HM 面前。
3. **Senior Solution Engineer / 高级架构师**：最容易聊得起来的同行，warm referral 的主要来源。
4. **行业解决方案负责人**：跨团队，认识的人多。
5. **最近公开分享过的任何团队成员**：愿意公开表达的人回复率最高。
6. **HR / 招聘者**：最后才找。他们能帮你进系统，但不能帮你被看见。

一家公司至少录入 2–3 人：一个 HM 级、一个同行级。同团队两条线，其中一条没回应时切换。

## 去哪找（国内语境）

| 渠道 | 怎么用 | 备注 |
|---|---|---|
| 脉脉 | 公司 + 关键词（解决方案 / 售前 / Agent / 大模型）；看"动态"和认证职位 | 大厂最全 |
| LinkedIn | 外企在华、海归、AU 团队；Experience 里的团队名最准 | 双足迹公司必用 |
| 会议议程 | QCon / ArchSummit / AICon / 云栖 / FORCE / WAIC 的议程页：讲师 + 团队 | 团队归属最准确的来源 |
| 公众号 / 技术博客 | 署名文章 = 愿意公开表达 | 留言区可以先互动 |
| GitHub | 平台 / 开源团队的 maintainer | 贡献一个 PR 是最暖的敲门 |
| 知乎 / 即刻 | 回答里提到"我们团队在做…"的人 | 即刻上 AI 从业者密度高 |
| 校友会 / 海归群 | 澳洲各校校友会、海归群 | 天然信任 |
| 猎头 | 专注 AI 方向的猎头，尤其外企 | 也是一条路径，别忽视 |

`pf people packet --company X` 会把以上清单和这个团队的研究摘要放在一起，你照着找。

## 路径怎么升级

```
L1 冷联系 ──第一条私信（不提内推）──► 回复 L2 ──给价值、聊问题──► 电话/会议 L3
      └──────────────── 对方是 HM/Lead ───────────────────────────► L4 HM 推荐 ──► L5 Sponsor
```

每一级升级都靠**一个具体动作**，不靠"多聊几次"：
- L1→L2：一个让对方 30 秒能回的具体问题。
- L2→L3：一次"给价值"（小实验结果、对比、资料），然后提议 15 分钟语音。
- L3→L4/5：对话建立后问 headcount；HM 认可你的作品或经历时，请他直接推。

系统按 `crm.log_touch` 的 kind 自动推进等级，不需要你手动改。

## 节奏（scoring.yaml/cadence）

- 第一条私信后 **60 小时**无回复 → follow-up 1（给价值）
- 再 **7 天**无回复 → follow-up 2（收尾 + 问是否有更合适的人）
- 两次无回复 → `parked`，切换同团队另一位（日报会提示）
- 收到回复 → **24 小时**内推进
- 对话建立后每 **7 天**一次价值触点
- 问了内推 → **5 天**后确认进度

## 人脉账户

`value_given` / `asks`：给了几次、要了几次。日报会把"只要不给"的人标出来。
规则很简单：**开口之前，账户里至少有一次给予。**

## 长期标签（docs/06 有详细表）

评估时模型会给每个人打 `hiring_now` 之外的标签：`peer / mentor / collaborator / distribution / au_cn_bridge / future_client_au / alumni`。
求职结束后，这些标签就是你 OPC、内容、回澳三条线的通讯录。

## 边界

- 只记录公开职业信息（职位、公开分享、主页链接）。不抓取，不存手机号。
- 不群发。日报每天 3–5 个动作是刻意的。
- 所有消息由你本人发送；系统只起草、记录、提醒。
- 对方明确不感兴趣 → 标 `parked`，不再触达；关系还在，下次有价值再联系。
