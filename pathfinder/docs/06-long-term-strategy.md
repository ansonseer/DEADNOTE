# 06 · 长期战略：从求职 Agent 到超级个体（2026 – 2028）

> 这个系统不只是找工作的工具。它是你未来两年三种资产的记账本：**人脉资产、作品资产、案例资产**。
> 求职是第一个用例；OPC（一人公司）、自媒体、2027 回澳做 FDE，用的是同一套数据和同一套动作。

---

## 1. 时间线（以 2028-03 签证到期为硬约束倒推）

| 阶段 | 时间 | 目标 | 系统里对应的东西 |
|---|---|---|---|
| **Pilot** | 2026-09 → 2026-10 | 20 家 → 50 岗 → 30 人 → Top 10；拿到 3 段真实对话、1 个内推 | `pf run-all`、作战卡、回复率 |
| **落地** | 2026-11 → 2027-01 | 入职一个偏 FDE 的岗位（售前/解决方案/AI 应用） | 机会进入 `interviewing → offer` |
| **积累** | 2027 全年 | 3 个可讲的交付案例（脱敏）、10+ 段温热关系、中英双语各一个内容阵地 | `assets` 表、人物 `tags`、每周内容动作 |
| **回流** | 2027-H2 | 在签证到期前回澳；三条路径同时准备（第 3 节） | `au_cn_bridge` 标签的人、双足迹公司 |
| **硬约束** | 2028-03 | 工作签证到期 | 签证问题请找注册移民代理（MARA）确认，本系统不给签证建议 |

关键判断：**2027 年这一年在中国的工作，不是"回不了澳洲的备胎"，而是你回澳洲时最大的差异化**——澳洲很少有人同时拥有"中国企业 AI 落地的一线经验 + 澳洲企业环境的理解 + 双语交付能力"。

## 2. 三条线并行，共用一个 CRM

```
求职线：找对团队 → 找对人 → 对话 → 内推 → 面试            （现在）
内容线：每个研究 / PoC / 对话 → 一篇公开内容 → social proof    （现在开始，永不停止）
桥梁线：双足迹公司 + 澳洲关系保温 + 中国出海企业            （每月一次最低动作）
```

每周最低动作（写进日报的"本周内容动作"）：
- 求职线：5 条第一条私信 + 所有到期 follow-up（日报会列）
- 内容线：1 篇公开内容（一个 PoC 小结、一次团队拆解、一个评测对比；中文发公众号/小红书，英文发 LinkedIn）
- 桥梁线：给 1 位澳洲人脉发一条有内容的消息（`tags` 含 `future_client_au` 或 `au_cn_bridge` 的人）

为什么内容线现在就开始：**作品敲门是回复率最高的开场**（templates/outreach/patterns.md 的模式 B），同一件作品既是私信素材、又是内容、又是 OPC 的案例库。做一次，用三次。

## 3. 2027 回澳的三条路径（同时准备，最后选一条）

**路径 A · 内部转岗**：在中澳双足迹公司工作，2027 转到澳洲团队。
候选（seeds.yaml 里 `au_footprint: true`，均需核实当年是否有 headcount）：阿里云（悉尼 Region / ANZ 团队）、AWS、微软、Thoughtworks（墨尔本/悉尼）、埃森哲、德勤/普华永道。
系统支持：这些公司在 `scan` 阶段有 `au_bonus`，评分里有 `au_bridge` 加分；`people_assess` 会给人物打 `au_cn_bridge` 标签。
动作：入职后第 3 个月起，和澳洲团队的人建立联系（同一家公司的人回复率远高于陌生人）。

**路径 B · OPC（一人公司）**：面向澳洲中小企业的"AI 流程改造 / FDE 服务"。
- 服务形态：诊断（1 周，固定价）→ PoC（2 周，固定价）→ 落地陪跑（按月）。这正是你在中国岗位上每天做的事，只是客户换成澳洲中小企业。
- 第一批客户从哪来：澳洲华人企业主（物流/进出口/会计/地产/诊所，你本来就有语言和信任优势）、中国出海企业的澳洲分支（需要懂两边的人）、你在悉尼做过的企业的转介绍。
- 需要的 social proof：3 个脱敏案例 + 1 次公开分享 + 1 个开源小工具。2027 年内能攒够。
- 行政（ABN、保险、合同、签证对自雇的限制）请分别找会计师与移民代理确认。

**路径 C · 澳洲 FDE / AI 解决方案岗**：Canva、Atlassian、四大银行、咨询公司、澳洲 AI 创业公司。
你的差异化故事："我在中国交付了 N 个企业 Agent 项目，知道从 PoC 到上线会死在哪一步。"
系统支持：同一套 `taxonomy.yaml` 加英文叫法就能扫澳洲市场；`profile.yaml` 的 `positioning` 换成英文版。

三条路径共用的资产：**案例、人脉、内容**。所以 2027 年不需要纠结选哪条，只需要把三种资产攒够。

## 4. 人脉资产：不只是"能不能帮我内推"

`people.tags` 的设计就是为了长期。每个人可以同时有多个标签：

| 标签 | 含义 | 你能给对方什么 | 保温频率 |
|---|---|---|---|
| `hiring_now` | 现在能影响招聘 | 一个具体问题、一个小实验结果 | 按 CRM 节奏 |
| `peer` | 同行，未来的合作者 / 互推者 | 交换踩坑、互相转发 | 每季度 |
| `mentor` | 比你早 5–10 年的人 | 认真执行他的建议并汇报结果 | 每季度 |
| `collaborator` | 可以一起做东西的人 | 一起写、一起做 PoC | 项目制 |
| `distribution` | 有渠道的人（媒体、社区、播客） | 好内容、一手观察 | 有内容时 |
| `au_cn_bridge` | 同时懂中澳的人 | 另一边的市场信息 | 每月 |
| `future_client_au` | 未来的澳洲客户 | 免费的小诊断、行业观察 | 每月 |
| `alumni` | 校友 / 同乡 | 天然信任，互相介绍 | 随缘但别断 |

**人脉账户**（`people.value_given` / `people.asks`）：每个人身上记着你给了几次、要了几次。日报里 asks > value_given 的人会被标出来："先给一次价值再开口"。这不是话术，是让关系能活两年的唯一办法。

## 5. 内容飞轮：每个动作都产出一次 social proof

```
研究一个团队 ──► 一篇"团队/产品拆解"（公众号 / LinkedIn）
做一个 PoC ────► 一篇"数据 + 结论"的小结 ──► 作品敲门私信
一段对话 ─────► 一条"我学到的一件事"（脱敏）
一次面试 ─────► 一篇"这家公司在解决什么问题"
```

规则：
- 只写你做过、量过、验证过的事。不点评公司，不泄露对话内容。
- 每篇末尾一句话定位（profile.yaml 的 `headline`），两年后这些内容就是 OPC 的官网。
- 记进 `assets` 表（`pf crm asset`），评分里 `proof_asset` 加分，作战卡"长期视角"会引用。

## 6. 风险与边界

- **签证**：所有关于回澳时间、离境时长、自雇是否允许的问题，只听注册移民代理的。把它当作硬约束输入，不要自己推断。
- **保密与竞业**：案例一律脱敏；写之前问一句授权。宁可少一个案例，不要丢一个关系。
- **精力**：日报每天只给 3–5 个动作。你的 Day 12 日记写过"焦虑快要把我淹没"——系统的作用是把"该做的"缩到一天能做完的量，剩下的交给排期。
- **信息真伪**：seeds.yaml 里的团队名全是假设；作战卡上"假设，待验证"的团队不要拿去写私信。

## 7. 每季度检查点（放进日历）

- [ ] 漏斗数字：联系了多少人、回复率、对话数、内推数、面试数
- [ ] 资产数字：公开内容篇数、脱敏案例数、可引用的作品数
- [ ] 人脉账户：`tags` 里非 `hiring_now` 的人有多少，最近 90 天有没有触点
- [ ] 桥梁线：澳洲那边的 5 个人最近一次联系是什么时候
- [ ] 三条回澳路径各自的最新证据（headcount、客户线索、岗位）
- [ ] 系统本身：`runs` 失败率、评分和直觉的偏差、要改的一处配置

---

## 8. 一句话总结

你正在把求职从"把简历发出去，看谁要我"变成"研究市场 → 找到问题的 owner → 用作品证明我能解决 → 再进入流程"。
这套动作在中国找工作时叫**内推**，在澳洲给企业做服务时叫**获客**，在自媒体上叫**建立信任**。
它们是同一件事。这个系统记的，就是这件事的账。
